# Responsive Sliding Login & Registration Portal 🚀

A modern, interactive, and fully responsive authentication form built from scratch.

## ✨ Features
* 🌓 **Dark/Light Mode Toggle**
* 📱 **Fully Responsive** (Perfect for Mobile & Desktop)
* 👁️ **Show/Hide Password** feature
* ⚠️ **Real-time Form Validation** (Password matching)
* 🔔 **Custom Interactive Popups** (Instead of boring alerts)

## 🛠️ Technologies Used
* HTML5
* CSS3 (Glassmorphism & CSS Variables)
* Vanilla JavaScript
* FontAwesome Icons
